02 / THE PERSON BEHIND THE CODE

A scientist by profession.
An educator by practice.

I work as a Project Scientist I at the India Meteorological Department, where I analyse climate and environmental data and build the Python pipelines that turn it into forecasts and reports. Before that, I completed a Master of Science in Information Science at the University of Arizona and a Bachelor of Technology in Computer Science from Cooch Behar Government Engineering College.

My teaching draws on practical work with rainfall data pipelines, machine learning and AI tools. Classes connect core concepts with real code: a first loop, an analysis workflow, model evaluation or a tool-calling agent.

Classes are one-to-one and built around what you're trying to get to: a course requirement, a job switch, a research project, or just wanting to finally understand the language your data lives in.

03 / LEARN WITH ME

What I teach

Classes are built around your level and your goal, from a first line of Python to a portfolio-ready ML project.

Python foundations

Syntax, data structures, functions, OOP, file handling and the habits that make code easy to read six months later.

Data science

Pandas, NumPy, exploratory data analysis, statistics, data cleaning and visualisation with Matplotlib and Plotly.

Machine learning

scikit-learn and TensorFlow/Keras: regression, classification, clustering, model evaluation and deep learning basics.

SQL & databases

Writing real queries, joins, aggregation and connecting a database to a Python or Django application.

Projects & portfolios

Turning coursework into a project you can show — structured, documented and pushed to GitHub.

Exam & interview prep

Coursework deadlines, university assignments, and coding-interview practice with real feedback.

Generative AI

Working with LLMs directly: prompting well, the Anthropic and OpenAI APIs, embeddings, and retrieval-augmented generation.

AI agents

Building agents that call tools and APIs — with frameworks like LangChain and LangGraph, from a single tool call to a multi-step workflow.
